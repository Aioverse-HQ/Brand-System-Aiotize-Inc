# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works with multi-package repos, or single-package repos to help you version and publish your code.

## Creating a changeset

To create a changeset, run:

```bash
pnpm changeset
```

This will prompt you to select the packages that have changed and the type of change (major, minor, patch).

## Releasing

When you're ready to release:

1. Merge your changes to `main`
2. The Release workflow will automatically create a Version PR
3. Merge the Version PR to publish to npm
