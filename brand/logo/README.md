# Logo Assets

This folder contains the canonical Aiotize logo files in SVG and PNG formats.

## Folder structure

```
logo/
├─ svg/   ← Master vector source files (use these whenever possible)
├─ png/   ← Raster exports for documents, slide decks, and email
└─ usage.md
```

## Available variants

| File name | Variant | Background |
|-----------|---------|-----------|
| `aiotize-logo-primary.svg` | Full color | White / light |
| `aiotize-logo-reversed.svg` | White wordmark | Dark / brand color |
| `aiotize-logo-mono-black.svg` | Monochrome black | White / light |
| `aiotize-logo-mono-white.svg` | Monochrome white | Dark |
| `aiotize-icon.svg` | Icon mark only | Any (check contrast) |

PNG equivalents are exported at **1×, 2×, and 3×** resolutions.
