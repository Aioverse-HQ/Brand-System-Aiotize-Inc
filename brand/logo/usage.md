# Logo Usage — Quick Reference

This file is a quick-reference companion to the full specification in [`docs/logo-usage.md`](../../docs/logo-usage.md).

## Which file should I use?

| Situation | File to use |
|-----------|------------|
| Website, app, digital UI | `svg/aiotize-logo-primary.svg` |
| Dark background | `svg/aiotize-logo-reversed.svg` |
| Print (single color) | `svg/aiotize-logo-mono-black.svg` |
| Email or document | `png/aiotize-logo-primary-2x.png` |
| Favicon / app icon | `svg/aiotize-icon.svg` |
| Social media avatar | `png/aiotize-icon-2x.png` |

## Critical rules

1. **Do not alter** the logo — no color changes, stretching, rotating, or adding effects.
2. **Maintain clear space** — keep a margin equal to the height of the "A" on all sides.
3. **Minimum digital size** — 80 px wide for the full lockup; 16 px for the icon mark.
4. **Approved backgrounds only** — see the full spec for the approved background color list.
