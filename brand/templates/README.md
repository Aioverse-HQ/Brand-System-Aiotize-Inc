# Templates

This folder contains ready-to-use templates for presentations, social media, and press / partner communications.

## Structure

```
templates/
├─ presentations/   ← Slide deck templates (Google Slides, PowerPoint, Keynote)
├─ social/          ← Social media frame templates (1:1, 16:9, 9:16 stories)
├─ email/           ← Email header and signature templates
└─ press-kit/       ← Press kit assets for media and partner use
```

## Presentations

Templates are provided in Google Slides format (primary) and PowerPoint / Keynote exports.

- `aiotize-deck-template.gslides` (link stored in `presentations/README.md`)
- `aiotize-deck-template.pptx`
- `aiotize-deck-template.key`

## Social media

Canvases are sized for major platforms:

| File suffix | Dimensions | Use |
|-------------|-----------|-----|
| `-square.fig` | 1080 × 1080 px | Instagram, LinkedIn post |
| `-landscape.fig` | 1920 × 1080 px | Twitter/X, LinkedIn cover |
| `-story.fig` | 1080 × 1920 px | Instagram/TikTok story |

## Press kit

The `press-kit/` folder contains:

- Logo files (pre-packaged zip for external download)
- Approved brand description (one-liner, two-line, paragraph)
- Official colour swatches
- Executive headshots (in `press-kit/headshots/`)

Partners and journalists should use only the assets in `press-kit/`. For questions contact **press@aiotize.com**.

## Usage rules

All templates must be used as provided. Do not alter fonts, colors, or logo placement. Customise only designated editable areas (e.g. text placeholders, image frames).
