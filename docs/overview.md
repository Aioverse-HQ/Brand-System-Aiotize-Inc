# Brand System Overview

## What is the Aiotize Brand System?

The Aiotize Brand System is the single source of truth for every visual and verbal decision made across Aiotize products, communications, and partnerships. It provides the assets, guidelines, and tools teams need to create experiences that are unmistakably Aiotize.

## Who is it for?

| Audience | Primary use |
|----------|-------------|
| Product designers | Figma libraries, logo files, design tokens |
| Front-end engineers | npm packages, CSS variables, token schemas |
| Content writers | Voice and tone guidelines, approved copy patterns |
| Marketing teams | Templates, illustrations, approved color palettes |
| External partners | Approved logo variants, usage rules, press kit |

## When to use this system

- Building a new product surface or feature
- Creating marketing, social, or press materials
- On-boarding a new design or engineering team member
- Reviewing whether a proposed design is on-brand

## Governance

The Brand System is maintained by the Aiotize design and engineering teams. Proposed changes go through a pull request review process — see [CONTRIBUTING.md](../CONTRIBUTING.md) for details.

Breaking changes to tokens or logo assets are announced in [CHANGELOG.md](../CHANGELOG.md) and versioned using semantic versioning so product teams can upgrade on their own timeline.
