# @aiotize/brand-mobile

Mobile platform exports for the Aiotize Brand System. Provides design tokens in Android XML and iOS Swift formats, generated from the same source token files used by the web package.

## Structure

```
packages/mobile/
├─ android/   ← Android XML resource files (colors, dimensions, styles)
├─ ios/       ← iOS / Swift token files
└─ README.md
```

## Android

Add the generated XML files to your Android project's `res/values/` directory:

```
res/
└─ values/
   ├─ aiotize_colors.xml
   └─ aiotize_dimensions.xml
```

Reference tokens in layouts:

```xml
<TextView
    android:textColor="@color/aiotize_color_brand_blue"
    android:textSize="@dimen/aiotize_typography_fontSize_md" />
```

## iOS / Swift

Import the generated Swift file into your Xcode project:

```swift
import UIKit

let primaryColor = UIColor(hex: AiotizeTokens.colorBrandBlue)
```

## Regenerating

Token output is generated by running `npm run build` inside the `tokens/` folder (see [`tokens/README.md`](../../tokens/build/README.md)). Android and iOS outputs are placed in `tokens/build/android/` and `tokens/build/ios/` respectively.

Copy the relevant files from `tokens/build/` into this package folder when preparing a release.

## Publishing

Publishing is handled by the release CI workflow (`.github/workflows/release.yml`) on tagged releases.
