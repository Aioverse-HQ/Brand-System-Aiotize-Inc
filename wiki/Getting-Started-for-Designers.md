## 🔧 Figma Integration

### Setting Up

1. **Import the Aiotize Figma library** (contact design team for access)
2. **Enable the brand tokens plugin** for auto-sync with design tokens
3. **Use the provided components** rather than creating custom ones

### Best Practices

- ✅ Use library components when available
- ✅ Apply styles from the brand library (not custom colors/fonts)
- ✅ Follow the 8px grid system for spacing
- ✅ Check accessibility before handoff

## 🖼️ Using Brand Assets

### Logos

```
brand/logo/
├── svg/
│   ├── aiotize-logo-primary.svg      ← Default on light backgrounds
│   ├── aiotize-logo-reversed.svg     ← Use on dark backgrounds
│   ├── aiotize-logo-mono-black.svg   ← Single-color print
│   ├── aiotize-logo-mono-white.svg   ← Single-color on dark
│   └── aiotize-icon.svg              ← App icons, favicons
└── png/
    └── [Various resolutions]
```

### Icons

- Use icons from `brand/icons/` for consistency
- Don't mix icon styles within the same interface
- Maintain consistent icon sizing (16px, 24px, 32px)

### Illustrations

- Use illustrations from `brand/illustrations/`
- Maintain aspect ratios when scaling
- Contact design team for custom illustration requests

## ♿ Accessibility Checklist

Before finalizing designs:

- [ ] Text meets WCAG 2.1 contrast requirements (4.5:1 for body text)
- [ ] Interactive elements have visible focus states
- [ ] Color is not the only way to convey information
- [ ] Touch targets are at least 44×44 px
- [ ] Text can be resized up to 200% without loss of content
