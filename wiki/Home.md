Choose your path based on your role:

- Access to logo files, icon sets, and illustration libraries
- Design token values for Figma integration

### For Developers

- Install the `@aiotize/brand-tokens` package
- CSS variables and JavaScript token imports
- Reference implementations

## 📁 Repository Structure

```
brand-system/
├── docs/           → Human-readable brand guidelines
├── brand/          → Canonical logo, icon, illustration & template assets
├── tokens/         → Design tokens (source + generated build output)
├── packages/       → Consumable npm / platform packages
└── examples/       → Reference implementations
```
