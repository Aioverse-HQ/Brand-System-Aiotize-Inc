# Voice and Tone

Voice is who we are. Tone is how we adapt to the situation. Together they shape every word in every Aiotize experience — from UI microcopy to long-form marketing.

---

## 🎙️ Our Voice

Aiotize's voice is built on four qualities:

| Quality | What it sounds like | What it doesn't sound like |
|---------|--------------------|-----------------------------|
| **🔍 Clear** | Direct sentences, plain language, no jargon | Tech-speak, acronyms without context, passive voice overuse |
| **💪 Confident** | Definitive claims backed by substance | Hedging, filler phrases ("kind of", "sort of", "basically") |
| **🤝 Warm** | Human, encouraging, empathetic | Cold, robotic, overly formal |
| **🧠 Smart** | Precise, insightful, forward-looking | Showy, verbose, using complexity to sound impressive |

---

## 🎨 Tone Guidance by Context

| Context | Appropriate Tone | Example |
|---------|-----------------|---------|
| **Product UI (empty states)** | Helpful, encouraging | "No results yet — try a different search term." |
| **Error messages** | Calm, solution-focused | "We couldn't save your changes. Check your connection and try again." |
| **Onboarding** | Warm, motivating | "You're set up! Here's where to start." |
| **Technical docs** | Precise, neutral | "Pass the `apiKey` parameter as a header string." |
| **Marketing headlines** | Bold, energetic | "AI that works as hard as you do." |
| **Notifications** | Concise, direct | "Report ready — view it now." |

## ✍️ Writing Rules

### 1. Lead with the benefit or the action
- ✅ "Analyze your data in seconds."
- ❌ "Aiotize Insight Engine v2 is now available."

### 2. Use active voice
- ✅ "We sent you a confirmation email."
- ❌ "A confirmation email has been sent."

### 3. Be specific
- ✅ "Upload files up to 100 MB."
- ❌ "There is a file size limit."

### 4. Avoid filler
- ✅ "Save changes"
- ❌ "Click here to save your changes"

### 5. Write for skimmers
Use headers, bullets, and **bold** for key information.

### 6. Inclusive language
Use "they/them" as default pronouns; avoid idioms that don't translate across cultures.

### 7. Capitalisation
Sentence case for UI labels and headings (e.g., "Create new project", not "Create New Project").

## 📖 Glossary of Preferred Terms

| ✅ Use | ❌ Instead of |
|--------|--------------|
| Email address | Email / e-mail |
| Log in (verb) / Login (noun) | Sign in / signin |
| Set up (verb) / Setup (noun) | Configure (for non-technical contexts) |
| Cancel | Close (for destructive actions that discard data) |
| Dashboard | Home screen (use "dashboard" consistently) |

---

## ✅ Quick Checklist

Before publishing any copy, verify:

- [ ] Is this **clear** — would someone new understand it immediately?
- [ ] Is this **confident** — does it avoid hedging?
- [ ] Is this **warm** — does it feel human?
- [ ] Is this **smart** — is it precise without being complex?
- [ ] Is this **accessible** — does it work for all audiences?
